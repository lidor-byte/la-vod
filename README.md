# L.A VOD

אפליקציית חיפוש סרטים שבניתי ב־React. האפליקציה מאפשרת לחפש סרטים דרך OMDb API, לראות רשימת תוצאות ולעבור לעמוד פרטים של כל סרט.

## מה עשיתי בפרויקט

- בניתי את האפליקציה עם React ו־Vite.
- השתמשתי ב־React Router DOM כדי לנווט בין דף החיפוש לבין עמוד הפרטים של כל סרט.
- שמרתי על סדר בפרויקט: כל העמודים נמצאים בתיקיית `Pages` והקומפוננטות החוזרות נמצאות בתיקיית `Components`.
- חיברתי את האפליקציה ל־OMDb API לחיפוש סרטים לפי שם, ולקבלת פרטים מלאים לפי `imdbID`.
- בכל תוצאה מוצגים שם הסרט, שנת היציאה, פוסטר אם יש וכפתור למידע נוסף.
- בעמוד המידע מוצגים שם הסרט, שחקנים, דירוג IMDb, תקציר, פוסטר וכפתור חזרה לתוצאות החיפוש האחרונות.
- הוספתי טיפול במצבים של חיפוש ריק, טעינה, חוסר בתוצאות ושגיאת רשת או API.
- עיצבתי ממשק רספונסיבי שמתאים גם למובייל, עם עיצוב קולנועי מקורי.

## הערה לעופר

עופר, בפרויקט הזה יישמתי את מה שלמדנו על חלוקה לקומפוננטות, `useState`, `useEffect`, קריאות API וניווט עם React Router. נעזרתי גם באתר שלך כמקור עזר והכוונה במהלך העבודה על הפרויקט. השתדלתי לשמור על קוד מסודר ועל חוויית משתמש ברורה בזמן החיפוש והמעבר לפרטי הסרט.

## הפעלת הפרויקט

אחרי שנכנסים לתיקיית הפרויקט, מריצים:

```bash
npm install
npm run dev
```

לאחר מכן פותחים בדפדפן את הכתובת שמודפסת בטרמינל, בדרך כלל:

```text
http://localhost:5173
```

## בדיקת Build

כדי ליצור גרסת ייצור של הפרויקט:

```bash
npm run build
```

הקבצים המוכנים לפריסה ייווצרו בתיקיית `dist`.

## פריסה

הפרויקט מוכן לפריסה ב־Netlify או ב־Vercel. בשני המקרים פקודת הבנייה היא:

```bash
npm run build
```

ותיקיית הפרסום היא:

```text
dist
```

במידה וסביבת הפריסה לא תומכת אוטומטית בנתיבי SPA, צריך להגדיר הפניה ל־`index.html`, כדי שקישורים כמו `/info/:imdbID` יעבדו גם בכניסה ישירה לעמוד.
